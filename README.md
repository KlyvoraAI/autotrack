# AutoTrack

A personal vehicle maintenance and expense tracker.

AutoTrack helps drivers manage vehicle profiles, mileage, maintenance schedules, service records, repairs, fuel expenses, and reminders.

## Development

This app is a Cloudflare Worker with static assets. Local vehicle data is stored in the browser in this initial release.

## Deployment

Deploy with Cloudflare Workers using the included `wrangler.jsonc` configuration. No external API key is required for the core app.
